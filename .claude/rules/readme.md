# READMEs

- `README.md` (ko) and `README.en.md` (en) are one document: line-for-line parallel, with identical
  code lines apart from comments. Change both together.
- Every command, flag and configuration key shown runs as written. Check by registering the
  document's schema examples as a plugin under an isolated `HATEL_CONFIG` and `HATEL_STATE_DIR`
  and running each command.
- The Korean README addresses outside readers in 합니다체.
- Keep to what a user needs: what hatel is for, how to start, commands by question and how to
  read results. Exhaustive contracts belong in `--help` and the skill.
